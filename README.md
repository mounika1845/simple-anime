# Cinematic Krishna Reveal Animation

This project uses Python, OpenCV, and NumPy to create a cinematic Krishna image reveal. It includes a glowing neon effect, animated dot reveal, mosaic transition, reflection effect, and smooth crossfade to the final image.

## Technologies

* Python
* OpenCV
* NumPy

## How to Run

Install the required libraries and place `krishna.png` in the same folder as the Python file.

```bash
pip install opencv-python numpy
python animation.py
```

Press **Q** or **Esc** to exit.
